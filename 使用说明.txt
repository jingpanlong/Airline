晾图 / Airline
Windows 原生截图晾图绳 · 可运行原型 v0.2.0

把截图，晾在屏幕边上。

开始使用
1. 解压整个压缩包，再双击 Airline.exe。请把 Airline.exe.config 放在程序旁边。
2. 每次启动会在右下角显示提示，重复运行也会提示正在运行。程序驻留通知区域。鼠标移到主屏幕最顶端，晾图绳展开；移开约半秒后收起。
3. 按 Ctrl + Alt + S，拖动框选区域，松开鼠标挂好截图。按 Esc 取消。
4. 按 Ctrl + Alt + L 或单击通知区域图标，也能展开晾图绳。
5. 退出请用右上角“•••”或托盘菜单里的“退出晾图”。退出不会清空截图。

每张截图可以做什么
• 单击：复制图片。为识别双击，复制会延迟约一个系统双击间隔。
• 长按约 0.55 秒：打开标注。支持画笔、方框、箭头、四种颜色与撤销。
• 标注完成：另挂一份标注图，保留原图；导出保持原始像素尺寸。
• 双击：打开独立大图预览。预览保持打开或最小化时仍能使用晾图绳；也可转交系统默认图片查看器。
• 拖到支持文件拖放的 App：图片浮层跟随鼠标，传递一个 PNG 副本，原图继续留在绳上。
• 拖到资源管理器文件夹：存下 PNG 副本，原图继续留在绳上。
• 拖到晾图绳右下角“放手不要”：把原图放入 Windows 回收站。
• 拖到 Windows 回收站：识别回收站目标后移除绳上的原图；回收站里的副本可恢复。
• 右键：复制、标注、预览、另存为、放入回收站。

接住 Windows 自带截图
默认监听剪贴板。使用 Win + Shift + S 截图并复制到剪贴板后，也会挂到绳上。
监听会接住所有复制到剪贴板的图片，无法可靠区分“截图”与其他图片。
如果只想使用内置截图，可在顶部“设置”关闭“接住剪贴板中的图片”。
程序自己的复制不会重复挂图。
程序不运行时，或图片尚未被读入就被其他剪贴板内容覆盖时，无法接住那张图片。

保存与隐私
截图默认保存在 %LOCALAPPDATA%\Airline\Images。
右上角“资料夹”可以直接打开这个位置。不会自动把截图放到桌面。
不设置张数上限，不按时间清理原图；更多截图分页显示，用 ‹ / › 翻页。
退出、重启程序都会从原图文件恢复。请保留这个资料夹并按需要备份。
图片缩放显示在绳上，不额外生成缩略图文件。
拖放时使用单独的 Outbox 副本，避免接收方的“移动”操作带走原图。
为兼容延迟读取文件的 App，副本保留一段时间；超过七天的 Outbox 副本在下次启动时清理。
原图只在主动丢弃时移除。磁盘满或写入失败会提示，不能承诺在存储故障时继续保存。
无账号、无上传、无遥测。程序不申请管理员权限。开机自启动默认关闭，可在设置中手动开启。
Windows 自带截图工具是否另存截图，由该工具自己的设置决定。

环境与当前范围
适用于 Windows 10 / 11，需 .NET Framework 4.7.2 或更高版本；推荐 4.8。
这是 WPF 原生桌面程序，未使用 Electron 或浏览器壳。
当前晾图绳位于主屏幕，内置区域截图按虚拟桌面取图，支持跨屏框选。
不同缩放比例的多屏、全屏游戏、远程桌面、受保护视频内容需要在实际设备上验证。
第三方 App 必须接受 Windows 文件拖放；不是每个 App 都支持。
本次完成编译、64 项自动检查及界面渲染检查；未对第三方 App 和外部回收站做端到端拖放实测。
当前为未签名的便携原型；正式发布前需完善签名、安装更新、实际设备兼容性测试。
